# Scratchpad

Parking lot for feature ideas and specs that aren't being built yet.

One file per idea. Each spec follows the same loose shape:

    ## Title
    Status: idea | planned | building
    Date: YYYY-MM-DD

    ## Problem
    ## Idea / Goal
    ## Key decisions / open questions
    ## Gotchas / notes

Nothing here is a commitment — it's a place to park an idea without losing it.
When an idea graduates to real work (an issue, a branch, or a docs section),
move it out of here and delete its file.

## Current contents

- `overview-dashboard.md` — multi-proxy overview dashboard + reverse proxy.
- `startup-templates.md` — save + replay the entire setup as a named template.
