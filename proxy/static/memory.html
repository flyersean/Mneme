Memory Management

Review stored chunks and set the injectable / removed flag. Removing a chunk does not delete it — the content stays and stays readable here. It only changes what Mneme uses: removed chunks are skipped by injection and by the model's memory search. Reversible at any time.  ·  Injected prompts →  ·  Chat →

Good enough, not perfect. Reviewing chunks one at a time reduces the impact of bad facts; it won't fully clean a polluted DB. The blunt instrument is the date filter — if a bad fact landed at a known time, narrowing to everything saved after it is the reliable way to catch what it contaminated.
