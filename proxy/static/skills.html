Skill Management

Review, edit and manage Mneme skills. A skill is a named procedure injected as-needed when it matches the current task (top-k by name/description/tags). Deactivate keeps a skill but stops injecting it; delete removes it entirely (from the registry and, for file-backed skills, from disk). Create writes a new skill. Edits create a new version; old versions are kept and can be restored.

Two tiers. The skills/ directory is the default install (loaded automatically). The optional library lives in skill-library/ — install one with scripts/install-skill.sh <name> to copy it into skills/. Skills shown here are those currently in the registry (default + anything installed).
