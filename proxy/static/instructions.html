Mneme — Injected Instructions

Every prompt Mneme injects into the model, in the order they fire during a conversation. Edit a box and click Save to change that prompt — it writes straight back to its file (the # when / vars / used_by header is metadata, not part of the prompt). Delete a file to revert to the built-in default.

Order = the flow of one conversation: the first three fire on every turn (context build), then the escalation prompts fire as a task gets harder — a few tool calls → many → stuck → concede. Not every prompt fires every turn.
